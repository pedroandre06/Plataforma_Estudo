Como resolver no deploy (Vercel → Project → Settings → Environment Variables):

  • DATABASE_URL: string de conexão do PostgreSQL (ex.: Neon). Sem ela o app tenta usar SQLite e, no disco somente leitura da Vercel, o site quebra.

Depois de salvar as variáveis, faça um novo deploy (Redeploy). As tabelas e o usuário admin são criados automaticamente no primeiro acesso.
