===== PAGINA 4 =====
O que é processamento de dados?
Converter dados brutos em informações úteis ou valiosas.
Neste processo as informações são coletadas, manipuladas 
e analisadas para se tornarem úteis.
Como estamos falando de altas volumetrias, o modelo de 
processamento irá determinar o processo ideal.

===== PAGINA 5 =====
Como funciona o batch?
• Ideal para cenários em que não é necessário realizar 
análises em tempo real.
• Processa as informações em intervalos regulares.
• Armazena os dados e os processa posteriormente.
• Menos complexo, porém mais lento.
• Usado geralmente em logs de sistemas, faturamentos 
ou relatórios recorrentes de tarefas não urgentes.

===== PAGINA 6 =====
Como funciona o streaming?
• Necessário em casos de processamento em tempo real 
ou quase real.
• Processamento contínuo conforme os dados são 
produzidos.
• Menor latência.
• Mais complexo em termos de infraestrutura ou 
manutenção.
• Usado em monitoramento de redes sociais, detecção 
de fraudes ou processamento de sensores IoT.

===== PAGINA 7 =====
Batch versus stream, qual é o melhor?
Depende do tipo de uso. Além disso, eles podem ser 
usados em conjunto.
O stream é mais indicado para uso quando o tempo é 
essencial e no momento em que os dados estão sendo 
recebidos.
Quando eles já foram coletados, podemos usar o batch em 
outros modelos de análises.

===== PAGINA 10 =====
Como funciona o Apache Spark? 
• Mecanismo de análise unificado para processamento 
de dados em grande escala.
• Projetado para executar em clusters distribuídos.
• Divide as tarefas e processa os dados de forma 
eficiente.
• Compatível com Hadoop YARN, Apache Mesos, 
Kubernetes, entre outros.

===== PAGINA 13 =====
Apache Spark versus Apache Hadoop, qual é 
o melhor?
Depende do tipo de processamento, infraestrutura e 
natureza das informações.
O Spark é muito mais rápido do que o Hadoop, 
especialmente para workloads que exigem repetição, 
processamento iterativo ou interativo. Hadoop é mais 
lento, mas pode ser mais adequado para grandes 
operações de batch que não requerem velocidade.

===== PAGINA 15 =====
Como funciona o aprendizado de máquina?
O aprendizado de máquina é uma subárea da IA que 
permite que os sistemas possam aprender com base nos 
dados consultados. 
Eles conseguem identificar tendências nas informações 
por meio de padrões.
Suas três categorias principais são: regressão, 
classificação e clustering.

===== PAGINA 16 =====
Regressão
Usada para prever valores numéricos contínuos com base 
em conjuntos de dados de entrada.
Exemplo: podemos prever o valor de uma casa com base 
em suas características, como: tamanho, localização, 
número de quartos, tamanho do pátio etc. Todos eles são 
dados de entrada.
Cenários de uso:
• Previsão de preços (imóveis, ações e produtos).
• Estimativa de vendas futuras.
• Previsão de temperatura ou condições climáticas.

===== PAGINA 17 =====
Classificação
Usada para prever categorias ou rótulos a partir de dados 
nos quais o objetivo é atribuir a entrada a uma das 
classes predefinidas.
Exemplo: classificar e-mails como “spam” baseado em 
características como remetente, texto ou conteúdo.
Cenários de uso:
• Detecção de fraudes.
• Classificação de e-mails.
• Classificação de imagens e reconhecimento facial.

===== PAGINA 18 =====
Clustering
Consiste em um tipo de aprendizado não supervisionado em 
que são agrupados dados similares sem rótulos e 
predefinidos.
Exemplo:
Segmentar clientes de uma loja em grupos com base no 
comportamento de compra (tipo de produto, frequência, 
valor e forma de pagamento).
Cenários de uso:
• Segmentação de clientes.
• Detecção de anomalias em redes de sensores.

Reflita sobre a seguinte situação
Uma empresa de comércio eletrônico está enfrentando 
dificuldades para monitorar as atividades em seu site, 
como o comportamento dos usuários, compras e tráfego 
geral, em tempo real. 
Eles atualmente utilizam um sistema de batch que 
processa os dados das transações e atividades dos 
usuários apenas ao final do dia. 
No entanto, a equipe de marketing quer tomar decisões 
mais rápidas para ajustar promoções em tempo real, 
especialmente durante eventos de alta demanda como a 
Black Friday, em que cada segundo conta.

===== PAGINA 21 =====
Reflita sobre a seguinte situação
A empresa quer implementar um sistema de processamento 
de dados em tempo real usando streaming para:
• Identificar picos de acessos e ações dos usuários em tempo 
real.
• Analisar o comportamento do usuário e as vendas no 
momento em que ocorrem.
• Gerar alertas instantâneos quando uma promoção atinge 
um número de vendas específico.
• Eles decidiram usar a plataforma Apache Kafka para ingerir 
os dados em tempo real e o Apache Spark Streaming para 
processá-los.

===== PAGINA 22 =====
Norte para a resolução
Por onde começar? 
Crie um pipeline de processamento de dados em streaming que 
seja capaz de:
• Capturar os dados de navegação e transações dos usuários em tempo 
real.
• Processar esses dados continuamente para calcular:
• O número de usuários ativos no site a cada minuto.
• A quantidade de vendas de um produto específico em tempo real.
• Gerar um alerta quando o número de vendas atingir um limite predefinido 
(ex.: 1000 unidades vendidas).
• Fornecer uma solução para visualizar os resultados em tempo real, 
utilizando algum painel ou dashboard.

===== PAGINA 23 =====
Norte para a resolução
Não se esqueça de:
Configuração do Apache Kafka.
Processamento com Apache Spark Streaming.
Geração de alertas.
Visualização dos resultados.
Com o sistema de processamento em streaming implementado, a empresa 
conseguirá monitorar em tempo real o comportamento dos usuários e ajustar 
suas campanhas de marketing de forma dinâmica, reagindo de forma mais ágil a 
picos de demanda e otimizando suas promoções.
